# SmartHouse
Проект "Умного дома" в системе КАСКАД

# Руководство по запуску
1. Склонировать версию проекта к себе на компьютер;
2. Зайти в файл `SmartHouse\config\config`;
3. Изменить значение поля `proj_path`, указав путь до папки, в которой лежит проект. Например: "C:/Sybcom/Project/SmartHouse";
4. Запустить систему "КАСКАД";
5. Нажать на кнопку "Зарегистрировать новый проект" (Ctrl + R)
6. В поле "Путь и имя проекта" выбрать путь до папки с проектом;
7. Поставить галочку в поле "Исполняемый";
8. Кликнуть правой кнопкой мыши на название проекта. Нажать на кнопку "Запустить проект";
9. Запустить интерфейс пользователя;
10. Открыть панель "Main.pnl".

# Описание проекта
- Демонстрационный проект модели умного дома по итогам прохождения обучения на Хабре.
